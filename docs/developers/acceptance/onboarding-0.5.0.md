## 使用与验证边界

- 创建组织和项目由用户在 Langfuse 页面完成；向导提供默认名称和引导，没有调用管理 API 代建资源。
- 新安装不导入旧配置、旧队列或旧发送账本，不自动扫描历史任务。
- 测试使用临时目录和合成凭证，没有修改正在使用的用户接入，也没有把模拟调用描述为新版本的真实模型任务。
- 本轮未使用新的桌面启动入口执行真实模型任务；Node/Docker 检查与入口编排、真实插件引擎和 Collector 分别核验。首次在实际用户环境安装后，仍应通过无敏感任务确认桌面采集与 Langfuse 页面可见性。
- 安装包未进行 Apple 签名或公证。系统对下载脚本的打开提示由用户按系统流程处理，安装器不移除隔离属性。
- 本地生成 ZIP 和 SHA-256 文件；没有自动公开仓库或发布 GitHub Release。
